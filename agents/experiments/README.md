# Experiments

Reproducible records explaining **why** a configuration exists. Copy [TEMPLATE.md](TEMPLATE.md) to
`NNNN-short-slug.md` (next free number). Register every experiment in [registry.md](registry.md).

Rules:
- Hypothesis before measurement. One primary variable changed per experiment.
- Follow `agents/benchmarking/methodology.md`; link raw result file names and baseline used.
- Conclusion states the decision (adopt / reject / defer) and follow-ups.
- Never delete records; mark superseded.
